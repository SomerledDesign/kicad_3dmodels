# kicad_3dmodels

These are original 3D models for KiCad from [Somerled.Design](https://somerled.design).

* [`resistors/`](resistors/): colour-banded ¼ W axial and hairpin resistors, the full E24 series from 1R to 10M plus 0R, and the generator scripts.
